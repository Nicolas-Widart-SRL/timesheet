# AGENTS.md

Native desktop timesheet app (Rust 2024, egui/eframe) for macOS and Windows. One user, one project,
weekdays only. The user-facing feature list is in `README.md`.

## Commands

```sh
cargo run --release
cargo fmt                                          # CI runs `cargo fmt --check`
cargo clippy --locked --all-targets -- -D warnings # CI denies every warning
cargo test --locked
cargo test screenshots -- --ignored                # refresh docs/screenshots/ after a visible UI change
cargo test -- --ignored                            # also writes sample October PDFs to target/
```

Run fmt, clippy and test before every commit: CI runs all three.

## Layout

- `src/model/`: domain data, calendar and aggregation rules shared by UI and PDFs. `store.rs` owns the
  JSON data file, backups and signed PDF copies.
- `src/ui/`: egui screens (`timesheet`, `past_months`, `settings`). Colors and both palettes live in
  `theme.rs`; reusable controls live in `widgets.rs`.
- `src/pdf/`: the two monthly exports. Layout builds drawing operations per page; `render.rs` draws
  them with krilla.
- `src/holidays.rs`: public holidays computed from the date alone (no network).
- `src/fonts.rs`: fonts embedded from `assets/fonts/`, shared by UI and PDFs.

## Rules

- Put business rules in `src/model/` so the UI and both PDFs agree. Totals go through `round_hours`;
  format with `fmt_hours` (UI) and `fmt_report` (PDF).
- The data file must stay readable by older and newer builds. A new field on `Data` or `Settings` gets
  `#[serde(default)]`; a renamed field keeps its old name via `#[serde(rename)]` or `alias`.
- `Store` never overwrites a file it could not read: it moves it aside as `timesheet.corrupt-<ts>.json`,
  or blocks saving for the session. Write user files through `write_atomic` in `store.rs`.
- Both themes meet WCAG 2.2 AA contrast. Add a new color to both `LIGHT` and `DARK` in `ui/theme.rs`,
  and add its text/background pairs to the `text_meets_wcag_aa_contrast` test. PDFs always use light colors.
- The design source is `mockups/` (git-ignored, may be absent). Match the existing look in `theme.rs`
  and `widgets.rs` when it is missing.

## Git

- Branch from `main` as `<type>/<topic>` (for example `feat/days-off`, `ui/hours-units`) and merge by PR.
- Commit subjects follow Conventional Commits: `type(scope): description`; CI rejects others.
  `feat` and `fix` become changelog entries, so use them only for user-facing changes.
- `CHANGELOG.md` is generated by git-cliff; edit it only during a release. Release steps are in
  `README.md` (`scripts/release.sh`).
